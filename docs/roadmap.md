# Roadmap

Completed in 0.1.0: deterministic domain engine, CLI, fixtures, exports, regression tests and CI.

Planned work (not implemented):

1. Formal versioned JSON Schema with nested-field validation.
2. Property-based tests and differential checks against independently maintained protocol implementations.
3. Benchmarks on representative large datasets and documented resource limits.
4. Optional chain adapters with explicit finality and provenance metadata.
5. Independent security review before any production integration.

Features here are intentions, not claims of current capability.
